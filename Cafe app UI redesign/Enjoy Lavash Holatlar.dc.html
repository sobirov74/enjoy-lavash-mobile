Three tiers, and the rule for choosing
Nothing loaded → full screen. 500, 503, offline, 401, 429, 404. The screen is blocked anyway, so use the space: one sentence, one primary action, one way out. Loaded but empty → in place. Savat, xabarlar, menyu bo'limi, ballar tarixi. The screen keeps its own chrome — tabs on Xabarlar and Menyu, the back button on Savat — and the state names the one action that fills it. Loaded, action failed → banner or field. 422, 409, to'lov xatosi. Never a full screen — the customer's work is on that screen and must not disappear.
